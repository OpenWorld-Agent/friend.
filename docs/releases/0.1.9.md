# Friend 0.1.9

## Update and installer repair / 更新与安装修复

On a shared network, GitHub's anonymous REST quota may be exhausted even while public
release downloads remain available. Friend now checks the official release assets when
GitHub returns a rate-limit response. The installer uses the same fallback and downloads
public archives without consuming the REST asset quota.

共享网络上的 GitHub 接口额度用完时，之前可能无法检查更新或安装。此版本自动改走
官方公开下载路径，仍校验版本清单、SHA-256 和程序身份。无需额外填写 GitHub 令牌。

- The latest manifest is pinned to one version before reading its checksums and package.
- Mismatched manifests, duplicate or unsafe checksum entries, and damaged downloads fail closed.
- Unrelated access errors and private repositories do not silently switch download channels.
- Existing Home, Records, language packs, data directory and connection settings are retained.
- The 0.1.8 release remains available; its published assets are not replaced.

## Installation / 安装

Use [the official release](https://github.com/OpenWorld-Agent/friend./releases/tag/v0.1.9).
After checking the installer against that release's `SHA256SUMS`:

```sh
python3 install.py --version v0.1.9 --clients codex,claude --start --autostart
```

An older app affected by this quota error needs this installer or the native archive once.
Later update checks use the repaired updater. Only configure the clients you actually use.
Back up existing data and restart MCP clients after upgrading. Use `py -3` on Windows.

## Service status at release preparation / 发布准备时的服务状态

The website and platform authorization brokers have moved to the replacement server.
The existing Mac's Gmail and GitHub connection reads and renewed Notion authorization
were checked. This does not establish that every user or platform has been reauthorized.

**The account, balance/payment and account-managed model routes still return
`account_upstream_pending_team_review`.** They await the team's backend handoff.
This release does not restore lost server account data, invent balances, or claim a
new live model upload/readback loop has passed. Saved records and cached translations
remain readable; generating new summaries requires a working configured model service.

官网和平台授权服务已迁移。当前 Mac 的 Gmail、GitHub 读取与 Notion 重新授权已验证；
不等于所有用户和平台都已恢复。**账号、余额/付款及账号模型仍待团队接回。**
旧摘要可以继续查看，生成新摘要仍需要可用的模型服务。此更新不更换用户的模型配置。

The Pipedream broker is still using its development project/environment and trusted
backend enrollment. Public production onboarding and other users' identity recovery
require the team to finish that deployment. They are not enabled by this installer fix.
